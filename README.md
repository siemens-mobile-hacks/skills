# Siemens Mobile Hacks skills

Agent skills for Siemens phone hacking and reverse engineering.

| Skill | Purpose |
|---|---|
| [ghidra-fullflash-setup](skills/ghidra-fullflash-setup/SKILL.md) | Set up a fullflash in Ghidra: memory map, partitions, RAM dumps, swilib types and symbols |

## Install

In Claude Code:

```
/plugin marketplace add siemens-mobile-hacks/skills
/plugin install siemens@siemens-mobile-hacks
```

Update with `/plugin marketplace update siemens-mobile-hacks`.
